# MED-8 简单 HTML 页面实施计划

> **给执行者：** 按任务顺序逐项实施，并在每个验证点读取命令输出后再进入下一步。

**目标：** 交付一个可直接打开预览的简单中文 HTML 页面。

**架构：** 使用单文件静态页面承载内容、样式和内联视觉资产；使用独立 Node 校验脚本覆盖页面基础结构要求。仓库不引入构建链，降低本地预览和维护成本。

**技术栈：** HTML、CSS、Node.js 内置模块。

---

### 任务 1：页面结构校验

**文件：**
- 校验：`scripts/validate-page.mjs`
- 验证：`index.html`

**步骤 1：编写页面结构校验**

校验 `index.html` 是否包含中文语言声明、标题、描述、主内容区、主标题、图片替代文本、行动入口、亮点区、焦点样式、减少动态效果支持和页脚。

**步骤 2：运行校验确认缺口**

运行：`node scripts/validate-page.mjs`

预期：如果页面缺少必要结构，输出 `页面校验失败：` 和具体缺失项。

**步骤 3：实现最小页面**

在 `index.html` 中提供自包含的中文静态页面，包括首屏文案、行动链接、内联 SVG 视觉资产、亮点说明、响应式布局和基础可访问性样式。

**步骤 4：运行校验确认通过**

运行：`node scripts/validate-page.mjs`

预期：输出 `页面校验通过。`

### 任务 2：文档与人工预览说明

**文件：**
- 修改：`README.md`

**步骤 1：补充预览说明**

在 README 中说明入口文件是 `index.html`，可直接用浏览器打开。

**步骤 2：补充校验说明**

在 README 中记录 `node scripts/validate-page.mjs` 命令。

**步骤 3：浏览器预览**

运行：在浏览器中打开本地 `index.html`

预期：页面标题、说明文案、行动链接、视觉插画、亮点区和页脚均可见。

### 任务 3：提交与交付

**文件：**
- 验证：`git status --short`

**步骤 1：查看改动**

运行：`git status --short`

预期：只包含 MED-8 相关页面、脚本、文档或计划文件。

**步骤 2：提交改动**

运行：

```bash
git add .
git commit -m "记录 MED-8 简单 HTML 页面方案"
```

预期：生成中文提交信息的提交。

**步骤 3：推送分支**

运行：`git push -u origin med-8-simple-html-page`

预期：远端分支更新完成。

**步骤 4：创建 PR**

运行：`gh pr create --title "添加简单中文 HTML 页面" --body "Resolves MED-8"`

预期：如果 PR 尚不存在，创建新 PR；如果 PR 已存在，保留已有打开状态的 PR。
