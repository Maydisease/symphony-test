# MED-8 简单 HTML 页面设计记录

## 目标

为 MED-8 提供一个可直接打开预览的简单中文静态页面，不依赖构建工具、包管理器或外部资源。

## 方案选择

推荐方案是单文件静态页面：`index.html` 内联样式、内联图标和内联视觉插画。这个方案最符合“简单 HTML 页面”的票据描述，交付和预览成本最低，也便于后续作为静态站点首页继续扩展。

备选方案一是拆分 `index.html` 与 `styles.css`。它更利于长期维护，但对当前需求增加了文件数量和预览心智负担。

备选方案二是引入前端框架。它适合复杂交互，但当前页面没有状态管理或路由需求，属于过度实现。

## 页面结构

页面使用语义化结构：`main` 作为主要内容容器，首屏包含标题、说明文案和行动链接；右侧展示内联 SVG 视觉资产；下方提供三个亮点说明和页脚信息。

布局在桌面端使用双栏，在窄屏下收拢为单列。按钮、亮点区和视觉说明保持稳定尺寸，避免移动端文字溢出。

## 视觉方向

视觉采用清爽的晨间工作台风格，使用暖纸色背景、青绿色主色、暖黄色和红色点缀。字体以中文可读性为优先，标题使用衬线字体形成轻量编辑感，按钮和辅助信息使用无衬线字体增强操作清晰度。

## 可访问性

页面声明 `lang="zh-CN"`，设置 viewport 和 description。图片带有替代文本，主要内容有可识别标题，链接具备键盘焦点样式，并通过 `prefers-reduced-motion` 尊重减少动态效果偏好。

## 验证方式

使用 `node scripts/validate-page.mjs` 校验页面的基础结构、元信息、视觉资产、行动入口、可访问性样式和页脚信息。再用浏览器打开本地 `index.html`，确认标题、行动链接和亮点区真实渲染。
